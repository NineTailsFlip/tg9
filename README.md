# TG9 — Telegram on 9 keys

An unofficial Telegram client for Android phones with a physical keypad/D-pad and no
touchscreen. It uses the interface and the key handling of the
[Nine suite](https://git.sr.ht/~timofurrer/nine) (L9, C9, P9, M9): one column of plain
text on black, a numbered `*` menu, a bottom hint bar, and the phone's own T9 input for typing.
Under the hood it runs [TDLib](https://github.com/tdlib/td), Telegram's official client library.

TG9 is not made by Telegram. It talks only to Telegram's servers.

## What works

- Sign in by phone number: the code, the two-step password, email verification, and registering
  a new account.
- The chat list in Telegram's order, with unread counts, mute state and a live T9 filter by name.
  `#` shows unread chats only.
- Chats: reading (oldest at the top, opening on the newest message), replying, replies to a
  specific message, senders' names in groups, sent/read ticks, day jumps with Left/Right,
  copying and deleting.
- Photos, videos, round video messages, GIFs and stickers: full screen, with Telegram's tiny
  preview shown while the file downloads. Up/Down steps to the previous/next photo or video in the
  chat. Photos zoom with OK and pan with the D-pad; videos pause with OK and seek 10 s with
  Left/Right. Files over 15 MB wait for OK before downloading. Saved to `Pictures/TG9` or
  `Movies/TG9`.
- Sending photos and videos from TG9's own gallery (`*` → Send photo or video), in the same
  one-column style: newest first under day headers, a thumbnail per row, Left/Right by day,
  OK to view full screen, `#` to mark up to 10 for an album, the call key to send. Photos are
  rotated by their EXIF data and scaled to at most 2560 px before upload.
- Voice messages and music: play/pause in place (OK or `#`); recording and sending voice
  messages (`*` → Record voice message).
- Files: `*` → Save to phone (to `Download/TG9`, or Music/Movies by type). Pictures and videos
  sent as files open in the viewer.
- Links, phone numbers, shared contacts and locations: `*` → Open link / Call / Open map.
- Polls: options and results in the message text.
- Notifications through TDLib's notification API, which follows each chat's own mute settings.
  "Mark as read" right from the notification.
- A background connection (a foreground service) so messages arrive without Google push.
  It can be turned off in Settings.

Keys are listed in the app itself: Settings → About → Key mapping.

## Building

You need JDK 17+, the Android SDK (platform 34, build-tools 34), NDK `27.2.12479018`, CMake,
Ninja and gperf. On macOS:

```bash
brew install openjdk@21 cmake ninja gperf
brew install --cask android-commandlinetools
sdkmanager --sdk_root="$HOME/Library/Android/sdk" "platforms;android-34" "build-tools;34.0.0" "platform-tools" "ndk;27.2.12479018"
```

1. Clone with both submodules, TDLib and nine-core:
   `git clone --recursive https://github.com/NineTailsFlip/tg9.git` (or, in an existing clone,
   `git submodule update --init`).
2. Build TDLib once (about 10 minutes; re-run after bumping `third_party/td`):
   ```bash
   scripts/build-tdlib.sh
   ```
3. Get your own API credentials at <https://my.telegram.org> → API development tools, and put
   them in `local.properties` (gitignored):
   ```properties
   sdk.dir=/Users/you/Library/Android/sdk
   tg9.apiId=1234567
   tg9.apiHash=0123456789abcdef0123456789abcdef
   ```
   Without them the app builds, and its login screen says what is missing.
4. Build:
   ```bash
   ./gradlew :app:assembleDebug
   ```
   You get one APK per ABI in `app/build/outputs/apk/debug/`. Keypad phones are ARM, so it's
   `arm64-v8a` or, for older 32-bit ones, `armeabi-v7a`.

Tests: `./gradlew testDebugUnitTest`.

## Layout

- `nine-core/` — a git submodule ([nine-core](https://github.com/NineTailsFlip/nine-core)).
  It holds the Nine suite's shared UI module `core/` (`:core`), copied unchanged from
  `~timofurrer/nine` at commit `ab73f97`, and the gallery `kit/` (`:kit`) shared with G9.
  After a change there, update the pointer with `git -C nine-core pull` and commit it.
- `tdlib/` — TDLib's Java API and `libtdjni.so`, both generated by `scripts/build-tdlib.sh`
  and not committed.
- `third_party/td` — TDLib, a pinned git submodule.
- `app/` — TG9 itself (`dev.tg9`): `tg/` (the TDLib client and cache), `auth/`, `chats/`,
  `chat/`, `media/`, `notify/`, `settings/`.

## Requirements and limits

- Android 14+ (minSdk 34), the same as the Nine suite.
- Not done yet: secret chats, captions on sent photos and videos, sending files, stickers and
  GIFs, voting in polls,
  animated (TGS) stickers (their still preview is shown), streaming a video before it has
  downloaded, calls, editing messages, folders and the archive, contacts and searching for new
  chats.
